\# ShopHub - Full-Stack E-Commerce Platform



A production-ready e-commerce web application built with Python, Django, and modern responsive frontend technologies.



\## Features

\- \*\*Product Catalog\*\*: Dynamic catalog with category filtering and keyword search.

\- \*\*Product Detail View\*\*: Dedicated product pages showing descriptions, pricing, and live inventory status.

\- \*\*Interactive Cart\*\*: Session-linked shopping cart with dynamic item quantity adjustments and removals.

\- \*\*Order Management \& Stock Tracking\*\*: Multi-field checkout flow with automatic inventory deduction upon order placement.

\- \*\*User Authentication\*\*: Secure user registration, login, and logout using Django authentication.

\- \*\*Admin Management\*\*: Full backend dashboard for managing categories, products, orders, and users.



\## Tech Stack

\- \*\*Backend\*\*: Python 3, Django

\- \*\*Database\*\*: SQLite3

\- \*\*Frontend\*\*: HTML5, CSS3, JavaScript
